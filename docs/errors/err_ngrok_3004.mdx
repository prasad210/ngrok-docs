
# Fixing ERR_NGROK_3004 (ngrok Gateway Error)

## **Error Message**
```
ngrok gateway error  
The server returned an invalid or incomplete HTTP response.
```

## **Cause**
This error usually happens when hosting a secure upstream service (`https://localhost:[PORT]`) but not configuring ngrok to send HTTPS traffic correctly.

## **Solution**
When starting ngrok, use the full upstream service address, including `https://`.  

### **For HTTPS APIs**
If your API is running on `https://localhost:[PORT]`, use:
```sh
ngrok http https://localhost:[PORT] --host-header=localhost
```

### **For HTTP APIs**
If your API is running on `http://localhost:[PORT]`, use:
```sh
ngrok http [PORT] --host-header=localhost
```


## **Further Help**
If the issue persists, contact ngrok support: **support@ngrok.com**
